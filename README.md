## 📂 Article Categories

### 1. 🛠️ Project Planning & Control

In-depth guides on core planning methodologies:

- **Work Breakdown Structure (WBS)** - Creating effective project hierarchies
- **Earned Value Management (EVM)** - CPI, SPI, EAC, ETC, TCPI calculations
- **Project Scheduling** - Critical Path Method (CPM) and resource leveling
- **Progress Measurement Systems (PMS)** - Weight-based and rule-based approaches
- **Cash Flow Forecasting** - S-Curve distribution and financial planning

### 2. 📅 Scheduling Software Tutorials

Step-by-step tutorials for industry-standard tools:

- **Primavera P6** - Enterprise project management
  - WBS creation and activity coding
  - Resource loading and leveling
  - Baseline management
  - DCMA 14-Point schedule health checks
  
- **Microsoft Project (MSP)** - Professional scheduling
  - Task dependencies and constraints
  - Custom fields and filters
  - Report generation
  - Integration with Excel

### 3. ⚖️ Claims & Delay Analysis

Specialized content on contractual claims:

- **Extension of Time (EOT) Claims** - Documentation and methodology
- **Delay Impact Analysis** - Time Impact Analysis (TIA) and Windows Analysis
- **Disruption Claims** - Loss of productivity calculations
- **Prolongation Costs** - Preliminary and general (P&G) cost assessment
- **Acceleration Claims** - Constructive vs. directed acceleration

### 4. 🎓 PMP & Professional Certification

Preparation resources for certifications:

- **PMP (Project Management Professional)** - PMI-based exam prep
- **PSP (Planning & Scheduling Professional)** - AACE certification
- **CCP (Certified Cost Professional)** - Cost engineering
- **Risk Management** - PMI-RMP preparation

### 5. 💼 Industrial Engineering Insights

Practical knowledge from the field:

- **Oil & Gas Projects** - EPC lifecycle management
- **Construction Management** - Site planning and coordination
- **Cost Control** - Budget tracking and variance analysis
- **Resource Management** - Manpower and equipment optimization
- **Contract Administration** - FIDIC and NEC contracts
